# دیسکافه (Discaf) — پلتفرم گیمینگ و دیسکورد ایرانیزه با جهان‌باز FC 27 🎮🇮🇷

پلتفرم مدرن گفتگو، ویس‌روم، تماس تصویری، اشتراک صفحه و متاورس جهان‌باز برای گیمرهای ایرانی، توسعه داده شده با **Next.js 16 + TypeScript + Tailwind CSS + Framer Motion**.

---

## 🚀 نحوه اجرای سریع با داکر (Docker & Docker Compose)

### روش اول: با استفاده از Docker Compose (ساده‌ترین روش)

```bash
# بیلد و اجرای کانتینر در پس‌زمینه
docker compose up -d --build

# مشاهده وضعیت کانتینر
docker compose ps

# مشاهده لاگ‌ها
docker compose logs -f
```

برنامه روی آدرس **`http://localhost:3000`** بالا خواهد آمد.

---

### روش دوم: با استفاده از Dockerfile مستقیم

```bash
# بیلد ایمیج
docker build -t discaf-app .

# اجرای کانتینر
docker run -d -p 3000:3000 --name discaf_container discaf-app
```

---

## 💻 اجرای در حالت توسعه محلی (بدون داکر)

```bash
# ۱. نصب پکیج‌ها
npm install

# ۲. اجرای سرور توسعه
npm run dev

# ۳. بیلد پروداکشن
npm run build
npm start
```

## 🌟 قابلیت‌های اصلی پلتفرم:
1. **جهان‌باز تمام‌صفحه FC 27 (FC 27 Open World)**:
   - انتخاب کاراکترهای سه‌بعدی با شماره پیراهن و کارت‌های اولتیمیت.
   - استادیوم آزادی با توپ فوتبال، شوت و ثبت گل با افکت کانفتی.
   - ورود به سالن سینما، دور آتیش کمپینگ، کلوپ آرکید و کافه.
2. **ارتباطات زنده صوتی، تصویری و وبکم (Voice & Video Call)**:
   - روم‌های صوتی با پینگ اختصاصی سرور تهران.
   - اشتراک‌گذاری تصویر مانیتور (Screen Share) با طراحی ریسپانسیو.
   - وبکم زنده گیمر همراه با فال‌بک نرم‌افزاری بدون خطا.
3. **احراز هویت و مدیریت پروفایل**:
   - ورود، ثبت‌نام و بازیابی رمز عبور (فراموشی رمز).
   - آیکون‌پک‌های وکتور اختصاصی برای آواتار کاراکترها.
   - ویرایش نام کاربری، وضعیت حضور و استاتوس بازی.
4. **ساخت سرور و کانال‌ها**:
   - کانال‌های متنی، صوتی، عمومی و خصوصی با قفل طلایی.
